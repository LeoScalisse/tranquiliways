# TranquiliHub Scene Notes

Monte a cena inicial com estes pilares:

- Um espaco central de chegada com fogo suave e pulsante
- Dois ou tres caminhos luminosos, ainda sem ramificacoes narrativas reais
- Camera parada ou com drift lento para reforcar calma
- Particulas leves para poeira de luz e respiracao do ambiente
- Audio ambiente sereno, sem texto nem locucao nesta fase

O objetivo da Fase 1 nao e personalizar o mundo pelo prompt.
O objetivo e provar:

- o app recebe input
- a sessao nasce
- a Unity abre
- o hub 3D hidrata a sessao via backend
