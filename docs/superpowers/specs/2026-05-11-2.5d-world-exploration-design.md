# Design Spec: Exploração 2.5D de DilemmaWorlds

**Data:** 2026-05-11  
**Status:** Aprovado  
**Escopo:** Nova tela de exploração interativa dos mundos gerados — pixel art character, hub com bifurcação de caminhos, salas 2.5D com ambientes dinâmicos e diálogo estilo Pokémon

---

## Problema

O app gera um `PlayableWorldV1` rico com caminhos, salas, hotspots e conteúdo emocional, mas a interface atual (`DilemmaWorldView`) exibe tudo como cards estáticos com gradiente. O usuário vê o conteúdo, mas não o *explora* — não há sensação de entrar num mundo, descobrir objetos, ou navegar de forma autônoma entre ambientes. A exploração imersiva que o produto promete não existe ainda.

---

## Solução

Nova rota `/ways/$sessionId/world` com exploração completa: o usuário escolhe seu pixel art character, entra num hub central com duas portas (uma por caminho), navega livremente entre salas 2.5D com parallax CSS e interage com elementos simbólicos que revelam insights progressivos.

---

## Fluxo de Telas

```
/ways/$sessionId           → card atual + botão "Explorar Mundo"
  ↓
/ways/$sessionId/world     → NOVA: exploração 2.5D
  ├─ CharacterSelect       → escolha de visual do personagem
  ├─ HubRoom               → sala central, duas portas
  ├─ PathCorridor          → corredor com N portas de ambiente (2-5)
  ├─ AmbienteRoom          → sala 2.5D com hotspots interativos
  └─ ElementDialogue       → diálogo progressivo ao tocar hotspot
```

---

## Ambientes Dinâmicos

Os ambientes por caminho variam de **2 a 5** com base no contexto do dilema. Os 4 ambientes atuais (quarto, sala, trabalho, família) continuam como preferência padrão para dilemas genéricos, mas o modelo escolhe os mais adequados ao contexto.

**Pool expandido de room IDs (~15 opções):**

```
quarto, sala, trabalho, familia, jardim, cozinha, academia,
varanda, cafe, biblioteca, carro, escola, escritorio, hospital, praia
```
Principais dilemas
  Caminho da Coragem Profissional — Escolher carreira/paixão vs expectativa familiar
  O Amor que Liberta — Continuar ou terminar um relacionamento
  Eu Sem Máscara — Ser autêntico vs agradar todo mundo
  A Rotina que Acende — Mudar hábitos diários (sono, estudo, redes sociais)
  Filho vs Sonho — Pressão familiar vs realizar sonho próprio
  Universidade ou Mundo Real — Continuar estudando ou tentar outra coisa
  Morar Sozinho — Independência financeira vs conforto da casa dos pais
  Amizade que Drena — Manter ou afastar amizades tóxicas
  O Corpo que eu Habito — Relacionamento com imagem corporal e saúde
  Deixar o Medo Decidir — Medo de falhar vs arriscar
  Vida com Propósito — Sentir que a vida tem sentido vs vazio existencial
  Futuro Digital vs Real — Tempo nas redes vs vida offline

**Exemplos de geração contextual:**
- Dilema de saúde → `quarto, academia, hospital, familia`
- Dilema de trabalho remoto → `escritorio, cafe, quarto, varanda`
- Dilema de relacionamento → `quarto, sala, familia, jardim`
- Dilema de propósito → `quarto, biblioteca, cafe, praia`

O número de ambientes por caminho pode variar entre si (um caminho pode ter 3 salas, o outro 4 — o modelo decide com base no que faz sentido narrativamente).

## Arquitetura

### Nova Rota

**Arquivo:** `src/routes/ways/$sessionId/world.tsx`

Carrega o `PlayableWorldV1` do localStorage via `sessionId`. Se não encontrar, redireciona para `/ways/$sessionId`.

### State Machine (hook `useWorldStateMachine`)

```ts
type WorldScreen =
  | { type: "character-select" }
  | { type: "hub" }
  | { type: "path-corridor"; pathId: "parado" | "mudanca" }
  | { type: "ambiente-room"; pathId: "parado" | "mudanca"; roomIndex: number }
  | { type: "element-dialogue"; pathId: "parado" | "mudanca"; roomIndex: number; hotspotId: string }
```

Transições livres entre hub, corredor e salas. Diálogo fecha e volta para a sala. Botão de fechar na HubRoom redireciona para `/ways/$sessionId`.

### Componentes Novos

| Componente | Arquivo | Responsabilidade |
|---|---|---|
| `WorldExplorer` | `src/components/world-explorer.tsx` | Container raiz, gerencia state machine |
| `CharacterSelect` | `src/components/world/character-select.tsx` | Tela de escolha de visual do personagem |
| `PixelCharacter` | `src/components/world/pixel-character.tsx` | Sprite CSS pixel art animado |
| `WorldHub` | `src/components/world/world-hub.tsx` | Sala central com duas portas |
| `PathCorridor` | `src/components/world/path-corridor.tsx` | Corredor com N portas de ambiente dinâmico |
| `AmbienteRoom` | `src/components/world/ambiente-room.tsx` | Sala 2.5D com parallax CSS e hotspots |
| `ElementDialogue` | `src/components/world/element-dialogue.tsx` | Caixa de diálogo progressivo estilo Pokémon |
| `useWorldStateMachine` | `src/hooks/use-world-state-machine.ts` | Hook com toda a navegação |

## Mudanças no Schema (model.ts e generation.ts)

### ROOM_IDS — pool expandido

```ts
export const ROOM_IDS = [
  "quarto", "sala", "trabalho", "familia",
  "jardim", "cozinha", "academia", "varanda",
  "cafe", "biblioteca", "carro", "escola",
  "escritorio", "hospital", "praia"
] as const;
```

### Schema de rooms — array dinâmico

`RoomIntentTupleSchema` (z.tuple fixo de 4) vira:

```ts
export const RoomIntentArraySchema = z
  .array(BaseRoomIntentSchema.extend({ id: z.enum(ROOM_IDS) }))
  .min(2)
  .max(5);
```

O `WorldIntentSchema` atualiza `paths[].rooms` para usar `RoomIntentArraySchema`.

O type `PathIntent.rooms` muda de `[RoomIntent, RoomIntent, RoomIntent, RoomIntent]` para `RoomIntent[]`.

### Prompt (generation.ts) — instrução de ambientes dinâmicos

Adicionar ao CONTRATO do prompt:

```
- cada path deve ter entre 2 e 5 rooms
- escolha os room ids mais adequados ao contexto do dilema
- os ids quarto, sala, trabalho e familia têm preferência para dilemas genéricos
- nunca repita o mesmo room id dentro do mesmo path
- os dois paths podem ter números e tipos de rooms diferentes se fizer sentido narrativo
```

Remover a instrução atual que exige exatamente 4 rooms em ordem fixa.

## Pixel Art Character

Implementado em CSS puro com `image-rendering: pixelated`. Sem sprite sheet — divs posicionadas absolutamente formam a silhueta.

**Personalização (salva em localStorage por sessão):**
- Tom de pele: 3 opções (claro, médio, escuro) → afeta cor da cabeça
- Cor de roupa: usa `colorHint` do caminho ativo como sugestão, mas o usuário pode trocar
- Sem nome, sem gênero explícito

**Animação:** oscilação sutil (float) com Framer Motion `animate={{ y: [0, -2, 0] }}` em loop — sem walking animation de sprite sheet.

---

## Visuais das Salas (AmbienteRoom)

Cada sala é renderizada com 3 camadas CSS em perspectiva:

```
[fundo distante]   — gradiente skyTop/skyBottom do RoomBlueprint.palette
[camada média]     — elementos decorativos baseados em propStory
[chão/primeiro plano] — ground + character + hotspots clicáveis
```

Perspectiva: `perspective: 800px` + `rotateX` sutil na camada de fundo cria profundidade sem Three.js.

Cada **hotspot** aparece como um elemento flutuante com pulse animation. Label curto visível sempre. Toque abre o `ElementDialogue`.

---

## Diálogo Progressivo (ElementDialogue)

Caixa fixa na base da tela, estilo Pokémon:

1. Aparece com slide-up Framer Motion
2. Exibe `hotspot.prompt` (pergunta curta)
3. Texto `hotspot.insight` revela letra por letra (intervalo 30ms)
4. Toque em qualquer lugar após reveal completo fecha o diálogo
5. Fecha com slide-down

---

## Token e API

Nenhuma mudança de endpoint necessária. O `PlayableWorldV1` gerado pelo pipeline atual já contém tudo que a exploração precisa: `hub`, `paths[].rooms[]`, `hotspots[].label/prompt/insight`, `propStory`, `climate`, `mood`.

**Ajuste de configuração aplicado:**
- `GEMINI_TIMEOUT_MS`: 25 000 ms → 35 000 ms (já aplicado)
- `GEMINI_MAX_OUTPUT_TOKENS`: mantido em 8 192 (cobre cenário máximo de 2 paths × 5 rooms ≈ ~4 200 tokens de output)

---

## Integração com Rota Existente

Em `src/routes/ways/$sessionId.tsx`, adicionar botão "Explorar Mundo" que navega para `/ways/$sessionId/world`. O card atual de DilemmaWorld permanece — a exploração é opcional e aditiva.

---

## O que NÃO está no escopo deste spec

- Multiplayer ou compartilhamento de mundos
- Trilha sonora ou efeitos de áudio
- Animação de walking em sprite sheet
- Geração de assets visuais por IA (imagens, texturas)
- Persistência de progresso dentro do mundo (qual sala foi visitada)

---

7. `ElementDialogue` com reveal progressivo
